Перед подачей тестовых воздействий необходимо проверить настройки коммутационного модуля в ПО «РЗА Тестер» (Руководство по эксплуатации «РЗА Тестер», пункт 5.3.4 «Настройка проекта»).

Для подачи воздействия на 1 модуль управления необходимо подключить РЗА Тестер через кабель с одним разъемом для СМ_15 следующим образом:

| ![[media/Параметрирование CM_15/Описание и работа релейной защиты/Общие рекомендации по проверке РЗА/7.png]] |
| :----------------------------------------------------------------------------------------------------------: |
|               **Рис. 7** Подключение РЗА Тестера для подачи воздействия на 1 модуль управления               |

При таком подключении по кабелю будут подаваться все токи и напряжения, которые есть в РЗА Тестере по сторонам «+» и «–».

Для подачи воздействия на 2 модуля управления одновременно необходимо взять другой кабель, с 2 разъемами для подключения к модулям управления:

| ![[media/Параметрирование CM_15/Описание и работа релейной защиты/Общие рекомендации по проверке РЗА/8.png]] |
| :----------------------------------------------------------------------------------------------------------: |
|               **Рис. 8** Подключение РЗА Тестера для подачи воздействия на 2 модуля управления               |

При таком подключении по каналу XS3 будут подаваться:
- Фазные токи (Ia, Ib, Ic);
- Фазные напряжения по стороне + (Ua+, Ub+, Uc+);
- Ток нулевой последовательности (3I0).

По каналу XS4 будут подаваться:
- Фазные напряжения по стороне – (Ua-, Ub-, Uc-).

## Условные обозначения тестовых воздействий

Для проверки какой-либо защиты необходимо настроить её уставки и подать воздействие в виде токов и напряжений определенных значений.

 >**Примечание:**
> В методиках проверки РЗА тестовые воздействия будут приведены в табличном виде и в виде пиктограмм.

### Тестовые воздействия в табличном виде

|  №  |       Ia, A / PIa, °       |         Ib, A / PIb, °         |        Ic, A / PIc, °        |               Ua, кВ / PUa, °               |                Ub, кВ / PUb, °                 |                Uc, кВ / PUc, °                | F (Гц)                 | Изменение <br>параметра |    Т, с     |
| :-: | :------------------------: | :----------------------------: | :--------------------------: | :-----------------------------------------: | :--------------------------------------------: | :-------------------------------------------: | ---------------------- | :---------------------: | :---------: |
|  1  |          10  / 0°          |          10 /  -120°           |          10 / 120°           |      $\frac {U_{ном}} {\sqrt{3}}$ / 0°      |      $\frac {U_{ном}} {\sqrt{3}}$ / -120°      |      $\frac {U_{ном}} {\sqrt{3}}$ / 120°      | $F_{ном}$              |         Ступень         |      5      |
|  2  | 1.3$\cdot I_{устРЗА}$ / 0° | 1.3$\cdot I_{устРЗА}$ /  -120° | 1.3$\cdot I_{устРЗА}$ / 120° | $\frac {U_{ном} \cdot 0.6} {\sqrt{3}}$ / 0° | $\frac {U_{ном} \cdot 0.6} {\sqrt{3}}$ / -120° | $\frac {U_{ном} \cdot 0.6} {\sqrt{3}}$ / 120° | 0.95$\cdot F_{устРЗА}$ |         Ступень         | $t_{срРЗА}$ |


В данном виде воздействий:
- Числовое значение - соответствует точному значению токов / напряжений / частоты / углов (в градусах);
- $I_{устРЗА}$ / $U_{устРЗА}$ / $F_{устРЗА}$ - соответсвует уставке токов / напряжений / частоты;
- $\frac {U_{ном}} {\sqrt{3}}$ - соответсвует амплитудному значению фазных напряжений;
- $F_{ном}$ - соответсвует номинальной частоте сети;
- Изменение параметра – вид изменения значений токов и напряжений. Может быть либо плавный, либо ступенчатый;
- Время (Т, с) – длительность подачи воздействия. Может быть или в абсолютных единицах или задаваться как время срабатывания РЗА ($t_{срРЗА}$).

 >**Примечание:**
> Данный вид воздействия аналогичен интерфейсу задачи воздействий РЗА Тестер

# Анализ результатов тестирования

## Источники данных для анализа

Для всестороннего анализа результатов тестирования РЗА используются три основных источника: панель MMI, программное обеспечение Telarm Lite и ПО «РЗА Тестер». Каждый из них предоставляет свой набор данных, которые дополняют друг друга.
### Панель MMI

Панель MMI отображает оперативную информацию о событиях в реальном времени. Основной источник — **журнал «События»**.

На панели MMI журнал «События» выглядит следующим образом:

|                                  **Рис. 11**  Журнал «События» на панели MMI                                  |

- время события.
