# Область применения

Настоящие методические рекомендации распространяются на конечный продукт TER - TER\_Sec10\_Etalon или устройства с применяемой функциональностью - [[Описание функциональностей, подфункциональностей, ролей, направлений, типов коммутационных модулей#Функциональность КРУ|КРУ]].

Рекомендации распространяются на модули управления CM\_15\_2(3/3I/3II/5/5С) модификацией (220\_1) и выше.

Для получения актуальной версии встраиваемого ПО и TELARM необходимо обратиться в ваше региональное представительство Таврида Электрик.

Контакты регионального представительства можно найти по [ссылке](https://www.tavrida.ru/ter/contacts/), предварительно выбрав Ваш регион или город.

# Подготовка к обновлению ПО

## Оборудование для обновления ПО

Для обновления встроенного ПО потребуется:

1. Ноутбук с установленным актуальными TELARM Lite **и** утилитой Section Tool;
2. Патч-корд (Ethernet-кабель) для подключения модуля управления к ПК
3. Необходимая версия встроенного программного обеспечения (прошивка), полученная по рекомендациям из пункта [[КРУ#Область применения|Область применения]];
4. Файл проекта;
5. Запасные модули управления CM\_15\_2(3/3I/3II/5/5С),  а также MMI (минимум 2 шт.). Перед выездом во все запасные модули должно быть установлено актуальное ПО и проверена их работоспособность.

## Подать оперативное питание на CM\_15

Подайте оперативное питание на все модули управления от сети переменного тока или ТСН. Разъемы питания указаны в таблице [[КРУ#^Power-connector|Разъемы питания у модулей управления]].

| СМ\_15\_5           | X4; X7          |

## Установить соединение с TELARM Lite

### Отдельно с каждой ячейкой

При соединении **с каждой ячейкой отдельно** необходимо:
1\)    Подключиться патч-кордом к модулю управления ячейки
2\)    В обозревателе баз выбрать соответствующую ячейку, затем в области «Подключение к устройству» на главном экране программы необходимо выбрать:
\- В графе серийный номер – «Автоопределение»
\- Пароль – 444444
\- Интерфейс – Ethernet
\- IP-адрес модуля управления
\- Порт - 9001

# Автоматическое обновление ПО

> **Примечание:**
> Автоматическое обновление ПО доступно только при индивидуальном подключении.
> Индивидуальное подключение – это способ подключения через физический интерфейс Ethernet.
> Для обновления нескольких ячеек необходимо подключаться к каждой через физический интерфейс Ethernet при помощи коммутатора.

## Установить соединение с SectionTool

Запуск утилиты осуществляется нажатием кнопки «Обновить» в интерфейсе TELARM Lite:

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/11.png]] |
| :---------------------------------------------------------: |
|   **Рис. 11** Кнопка «Обновить» в интерфейсе TELARM Lite    |
|                                                             |

Произвести автоматический поиск CM\_15 по интерфейсам кнопкой «Autodetect» / «Автопоиск» или добавить вручную известный IP с помощью кнопки «Add…» / «Добавить…». CM\_15 добавится в базу данных (БД) устройств SectionTool.

|                ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/12.png]]                |
| :---------------------------------------------------------------------------------------: |
| **Рис. 12** Автоматический поиск и ручное добавление CM\_15 в список устройств SectionTool |

Выделить необходимое устройство в БД и нажать кнопку «Connect» / «Подключить», предварительно разорвав соединение в TELARM, если оно было ранее установлено. Произойдет подключение.

## Загрузить ВПО

В SectionTool перейти на вкладку «Автоматическое обновление», выбрать соответствующий файл прошивки ВПО (см. пункт [[КРУ#Область применения|Область применения]]) и нажать **«Обновить до версии XX.X.X»**.

|        ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/13.png]]         |
| :------------------------------------------------------------------------: |
| **Рис. 13** Поле задания файла прошивки для автоматического обновления ВПО |

> **Примечание:**
> Обновлять ПО CM\_15 автоматически приведет к выводу защит, переводу в местный режим данного устройства.

Допускается выполнять обновление сразу нескольких СМ\_15. Для этого перед нажатием клавиши «Обновить» необходимо выделить в БД SectionTool необходимые модули управления. (Ctrl+ЛКМ или Shift+ЛКМ).

## Завершение обновления ВПО

Автоматическое обновление выполняется около 10-20 минут.

По завершению автоматического обновления программа сообщит об успешном завершении сообщением со следующим содержанием:

<span style="background-color: gray; color: black; padding: 6px 10px; border-radius: 4px;line-height: 1.8;">
  2026-05-18 14:18:52.649 INFO <b><span style="background-color: gray; color: blue; padding: 6px 10px; border-radius: 4px;line-height: 1.8;">192.168.102.11 / 0 / 22800037 Обновлятор2000 всё ПО обновлено</b> </span>
</span>

При этом SectionTool автоматически восстановит функциональность и другие настройки модуля управления. После таймаута программа автоматически восстановит соединение с модулем.

В случае, если автоматическое обновление ПО выполнить не удалось, появится запись со следующим содержанием:

<span style="background-color: gray; color: black;padding: 6px 10px; border-radius: 4px;line-height: 1.8;">
  2026-05-18 15:18:52.649 INFO<b><span style="background-color: gray; color: #B00000;padding: 6px 10px; border-radius: 4px;line-height: 1.8;">192.168.102.11 / 0 / 22800037 Обновлятор2000 не смог обновить ХХХ. Повторите попытку</b></span>
</span>

В указанном случае необходимо выполнить перезапуск модуля управления по питанию и выполнить загрузку ПО снова. Если за три попытки прошить модуль управления не удалось, прекратите попытки, свяжитесь с сервисно-гарантийной службой.

## Ввести режим ArcNet

> **Примечание:**
> Для секций с проводным каналом межфидерной связи

Для этого сервисном меню:

1. выбрать пункт «ArcProt configuration» или «Конфигурация ДЗ» и нажать кнопку «Enter» («Ввод»);
2. Выбрать пункт «ArcNet mode» или «Режим ArcNet» и нажать кнопку «Enter» («Ввод»);
3. Затем нажатием кнопки «▲» или «▼» прокрутите до значения «Enable» или «Ввести»;
4. Снова нажмите кнопку «Enter» («Ввод»);
5. Подтвердите изменения, ещё раз нажав кнопку «Enter» («Ввод»).

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/14.png]] |
| :---------------------------------------------------------: |
|               **Рис. 14** Ввод режима ArcNet                |

Также необходимо проверить, что на панелях управления в правом нижнем углу всех фидеров горит соответствующий индикатор.

> **Примечание:**
> В случае если версия ArcNet не была обновлена требуется выполнить процедуру [[КРУ#Загрузить ВПО|Загрузить ВПО]] повторно.

## Сбой процедуры обновления

Если в процессе обновления на каком-то из этапов произошел сбой, программа автоматически повторит попытку обновления. После 10 неуспешных попыток, программа сообщит что она не смогла выполнить обновление.

<span style="background-color: gray; color: black;padding: 6px 10px; border-radius: 4px;line-height: 1.8;">

</span>

Напротив версии ПО устройства, на котором обновление завершилось с ошибкой, будет выставлен красный значок.

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/21.png]] |

Если прошить модуль управления не удалось, необходимо перезапустить процесс обновления, п. 3.1.2.

Может возникнуть следующее сообщение, с возможностью продолжить обновление, с места его прерывания.

## Восстановление настроек при помощи TELARM Lite

### Установите соединение с TELARM Lite

Установить соединение с TELARM согласно пункту [[КРУ#Установить соединение с TELARM Lite|Установить соединение с TELARM Lite]]

### Восстановить значения счетчиков

В интерфейсе TELARM Lite выполнить действия согласно рисунку [[КРУ#^Restoring-counter-values|Рис. 31]], используя значения полученные в пункте [[КРУ#Зафиксировать считанные значения|Зафиксировать считанные значения]]

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/26.png]] |
| :---------------------------------------------------------: |
|        **Рис. 26** Восстановление значения счетчиков        |

^Restoring-counter-values

### Восстановите уставки

Уставки, полученные в пункте [[#Запросить уставки]], следует записать в CM по нажатию кнопки «Записать уставки» и дождаться пока все уставки будут загружены в CM.

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/27.png]] |
| :---------------------------------------------------------: |
|      **Рис. 27** Загрузка в CM ранее скачанных уставок      |

### Запросите уставки

В области «Настройки (уставки)» на главном экране TELARM Lite произвести выгрузку уставок, нажав на кнопку «Вычитать все уставки» (см. [[КРУ#^Unloading-of-settings|Рис. 9]]) и дождаться, пока придут все уставки от CM.

### Сверьте запрошенные уставки с исходным значением уставок

Для того, чтобы выделить различающиеся уставки необходимо нажать на кнопку «Различия».

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/28.png]] |
| :---------------------------------------------------------: |
|                **Рис. 28** Кнопка «Различия»                |

При наличии отклонений повторить пункт [[#Восстановите уставки]].

### Ввод РЗА в работу

Нажав соответствующую кнопку на главном экране TELARM Lite, ввести РЗА.

| ![[media/Параметрирование CM_15/Обновление ВПО/КРУ/29.png]] |
| :---------------------------------------------------------: |
|                    **Рис. 29** Ввод РЗА                     |

### Запросите состояние системы

Запросите состояние системы, выполнив действия согласно пункту [[#Запросить состояние системы и журналы]].

### Запросите состояние системы

Запросите состояние системы, выполнив действия согласно пункту [[#Запросить состояние системы и журналы]].

### Сверьте значения данных сигнализации на MMI и в состоянии системы

Открыть скачанный системный статус и сверить полученные данные сигнализации и счетчиков со значениями, отображаемыми на панели MMI.

> **Примечание:**
> Особо стоит обратить внимание на следующее:
>
> - Положение главных контактов в данных индикации драйвера соответствует реальному.
> - Глобальный ключ РЗА должен быть в состоянии «Введено»
> - Состояние защитных элементов. Глобальные ключи необходимых защитных элементов должны быть в состоянии «Введено».
> - ЗЗЗ должна быть выведена
> - Введена необходимая группа уставок.
> - Введен учет электроэнергии на тех присоединениях, где это необходимо.
