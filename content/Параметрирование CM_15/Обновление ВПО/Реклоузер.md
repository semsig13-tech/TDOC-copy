# Область применения

Настоящие методические рекомендации распространяются на следующие продукты:

- TER\_Rec15\_Smart1\_R7;
- TER\_Rec15(25)Al1\_L5M;
- TER\_Rec35\_Smart1\_Tie7;
- TER\_Rec35\_Smart1\_Sub7;
- TER\_VCB15\_LD8 (Shell2)\_SRF2;
- TER\_VCB15\_LD8 (Shell2)\_SRD2;
- TER\_VCB15\_LD8 (Shell2)\_SF2;
- TER\_VCB15\_HD1\_3CS\_6VS04 (6VS\_3CAS);
- TER\_VCB15\_Shell2\_3CS\_6VS04 (6VS\_3CAS);
- TER\_VCB15\_MD1\_3CS\_6VS04;
- TER\_OVCB35\_Smart\_7C (7CS/1C/9CS)

С применяемой функциональностью - [[Описание функциональностей, подфункциональностей, ролей, направлений, типов коммутационных модулей#Функциональность реклоузера|Реклоузер]].

Рекомендации распространяются на модули управления CM\_15\_4(5/5С/6) модификацией (220\_1) и выше.

Для получения актуальной версии встраиваемого ПО и TELARM необходимо обратиться в ваше региональное представительство Таврида Электрик.

Контакты регионального представительства можно найти по [ссылке](https://www.tavrida.ru/ter/contacts/), предварительно выбрав Ваш регион или город.

# Подготовка к обновлению ПО

## Оборудование для обновления ПО

Для обновления встроенного ПО потребуется:

1. Ноутбук с установленным актуальными TELARM Lite **и** утилитой Section Tool;
2. Патч-корд (Ethernet-кабель) для подключения модуля управления к ПК
3. Необходимая версия встроенного программного обеспечения (прошивка), полученная по рекомендациям из пункта [[Реклоузер#Область применения|Область применения]];
4. Файл проекта
5. Запасные модули управления CM\_15\_4(5/5С/6),  а также MMI. Перед выездом во все запасные модули должно быть установлено актуальное ПО и проверена их работоспособность.

## Подать оперативное питание на CM\_15

Подайте оперативное питание на все модули управления от сети переменного тока или ТСН. Разъемы питания указаны в таблице [[Реклоузер#^Power-connector|Разъемы питания у модулей управления]].

Разъемы питания у модулей управления: ^Power-connector

| Модуль управления | Разъемы питания |
| ----------------- | --------------- |
| CM\_15\_4           | X2; X5          |
| CM\_15\_5           | X4; X7          |
| CM\_15\_6           | X2; X5; X8; X11 |
| СМ\_15\_5С          | S2; D3          |

> **Примечание:**
> Обновлять ПО CM\_15 при питании только от батареи запрещено!

## Установить соединение с TELARM Lite

В обозревателе баз фидеров выбрать соответствующий реклоузер (выключатель), затем в области «Подключение к устройству» на главном экране программы необходимо выбрать интерфейс подключения (Ethernet или Wi-Fi), IP-адрес устройства, а также ввести пароль (по умолчанию 444444).

По умолчанию IP-адрес:

- для Wi-Fi: 192.168.100.11;
- для Ethernet: 192.168.102.11.

Из области «Счетчики ресурса» на главном экране программы TELARM Lite зафиксировать значения:

- Циклов ВО (Total CO);
- Износ контактов (Contact wear);
- Ресурс АБ% (RBLT или Residual battery lifetime).

Эти значения нужно будет ввести после прошивки.

# Автоматическое обновление ВПО

## Установить соединение с SectionTool

Запуск утилиты осуществляется нажатием кнопки «Обновить» в интерфейсе TELARM Lite:

| ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/6.png]] |
| :--------------------------------------------------------------: |
|      **Рис. 6** Кнопка «Обновить» в интерфейсе TELARM Lite       |

Произвести автоматический поиск CM\_15 по интерфейсам кнопкой «Autodetect» / «Автопоиск» или добавить вручную известный IP с помощью кнопки «Add…» / «Добавить…». CM\_15 добавится в базу данных (БД) устройств SectionTool.

|             ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/7.png]]             |
| :--------------------------------------------------------------------------------------: |
| **Рис. 7** Автоматический поиск и ручное добавление CM\_15 в список устройств SectionTool |

Выделить необходимое устройство в БД и нажать кнопку «Connect» / «Подключить», предварительно разорвав соединение в TELARM, если оно было ранее установлено. Произойдет подключение.

## Загрузить ВПО

В SectionTool перейти на вкладку «Автоматическое обновление», выбрать соответствующий файл прошивки ВПО (см. пункт [[#Область применения]]) и нажать **«Обновить до версии XX.X.X»**.

|     ![[media/Параметрирование CM_15/Обновление ВПО/Реклоузер/8.png]]      |
| :-----------------------------------------------------------------------: |
| **Рис. 8** Поле задания файла прошивки для автоматического обновления ВПО |

> **Примечание:**
> Обновление ПО CM\_15 автоматически приведет к выводу защит, переводу в местный режим данного устройства!

Допускается выполнять обновление сразу нескольких СМ\_15. Для этого перед нажатием клавиши «Обновить» необходимо выделить в БД SectionTool необходимые модули управления. (Ctrl+ЛКМ или Shift+ЛКМ).

## Завершение обновления ВПО

Автоматическое обновление выполняется около 10-20 минут.

По завершению автоматического обновления программа сообщит об успешном завершении сообщением со следующим содержанием:

<span style="background-color: gray; color: black; padding: 6px 10px; border-radius: 4px;line-height: 1.8;">
  2026-08-12 15:18:09.370 INFO <b><span style="background-color: gray; color: blue; padding: 6px 10px; border-radius: 4px;line-height: 1.8;">192.168.102.11 / 0 / 00900005 Updater2000 all software has been upgraded</b> </span>
</span>

При этом SectionTool автоматически восстановит функциональность и другие настройки модуля управления. После таймаута программа автоматически восстановит соединение с модулем.

В случае, если автоматическое обновление ПО выполнить не удалось, появится запись со следующим содержанием:

<span style="background-color: gray; color: black;padding: 6px 10px; border-radius: 4px;line-height: 1.8;">
  2026-08-12 15:25:21.091 ERROR<b><span style="background-color: gray; color: #B00000;padding: 6px 10px; border-radius: 4px;line-height: 1.8;">192.168.102.11 / 0 / 00900005 Updater2000 failed: Canceled</b></span>
</span>

В указанном случае необходимо выполнить перезапуск модуля управления по питанию и выполнить загрузку ПО снова. Если за три попытки прошить модуль управления не удалось, прекратите попытки, свяжитесь с сервисно-гарантийной службой.

### Сверьте значения данных сигнализации на MMI и в состоянии системы

Открыть скачанный системный статус и сверить полученные данные сигнализации и счетчиков со значениями, отображаемыми на панели MMI.

> **Примечание:**
> Особо стоит обратить внимание на следующее:
>
> - Положение главных контактов в данных индикации драйвера соответствует реальному.
> - Глобальный ключ РЗА должен быть в состоянии «Введено»
> - Состояние защитных элементов. Глобальные ключи необходимых защитных элементов должны быть в состоянии «Введено».
> - ЗЗЗ должна быть выведена
> - Введена необходимая группа уставок.
> - Введен учет электроэнергии на тех присоединениях, где это необходимо.
