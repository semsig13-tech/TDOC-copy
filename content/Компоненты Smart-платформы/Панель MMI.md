# Назначение

Панель управления предназначена для управления и снятия показаний в местном режиме работы. В составе шкафа управления панель подключается к модулю управления СМ\_15.

Панель управления представляет собой кнопочный пульт управления с дисплеем, выполненным по OLED технологии. Для удобства пользователя на панель вынесены кнопки быстрого ввода / вывода наиболее часто используемых защит, кнопка выбора активной группы уставок, кнопка выбора режима управления (местное или дистанционное). Дополнительно на панель вынесены кнопки навигации меню, кнопки включения и отключения выключателя.

С панели управления также возможно выполнение следующих функций:

- настройка системных параметров модуля управления;
- настройка релейной защиты и автоматики;
- настройка функций учета электроэнергии;
- настройка коммуникационных параметров;
- просмотр текущих показаний электрических величин;
- просмотр журналов;
- просмотр показаний счетчиков.

# Внешний вид

## Модификация панелей управления и индикации

На панели управления расположены:

- дисплей;
- индикаторы состояния коммутационного модуля и защит;
- кнопки навигации по меню;
- кнопки ввода/вывода защит;
- кнопки управления коммутационным модулем.

### Панель MMI\_2

Для панели MMI\_2 появилась новая наклейка, позволяющая программировать кнопки и светодиоды.

Основные изменения относительно MMI\_1:

- панель с кнопками 0, 4 – 9 без обозначений;
- цвет кнопок управления коммутационным модулем (согласно ГОСТ 12.2.007.0-75). Включить – зеленая, Отключить – красная.

| ![[media/Компоненты Smart-платформы/Панель MMI/2.png]] |
| :----------------------------------------------------: |
|        **Рис. 2** Панель управления MMI\_2(RU\_4)        |

Под программируемыми светодиодами понимаются светодиоды С1 – С6.
Цвет светодиодов остается красным.
Любой светодиод имеется возможность сделать мигающим при его активации.
Обозначение светодиодов реализуется на специальной наклейке TER\_SGdet\_Label\_192.

| ![[media/Компоненты Smart-платформы/Панель MMI/3.png]] |
| :----------------------------------------------------: |
|        **Рис. 3** Наклейка TER\_SGdet\_Label\_192         |

Наклейки для обозначения кнопок и светодиодов имеют одинаковый размер. Комплект наклеек будет входить в комплект поставки с оборудованием.

# Структура меню

Структура меню панели управления построена по иерархическому принципу. Переход по меню осуществляется с помощью кнопок навигации. При нажатии на кнопку «Ввод» выполняется переход на один уровень вниз. При нажатии на кнопку «Отмена» выполняется переход на один уровень вверх.
