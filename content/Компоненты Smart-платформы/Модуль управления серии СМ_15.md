# Назначение

Модули управления серии СМ\_15 предназначены для:

- управления коммутационным модулем;
- реализации функций измерения токов, напряжений совместно с комбинированными датчиками тока и напряжения в составе коммутационного модуля;
- реализации функций РЗА;
- реализации функции учета электроэнергии;
- реализации функций передачи данных;
- реализации функций управления и сигнализации через дискретные входы/выходы.

#### Печатный узел MPU

^mpu

В модулях управления СМ\_15\_2 установлен печатный узел MPU-4, во всех остальных модулях используется печатный узел MPU-5.

###### Печатный узел MPU-4

Данный конструктивный узел содержит:

- сигнальный процессор (DSP), реализующий функции РЗА;
- аналоговый измеритель каналов фазных напряжений, фазных токов и тока нулевой последовательности, фазных токов для коммерческого учета.

MPU-4 содержит [[Модуль управления серии СМ_15#^4|следующие разъемы]]:

- для подключения панели управления MMI (Х4);
- для подключения измерительных цепей (Х5).

###### Печатный узел MPU-5

Данный конструктивный узел дополнительно к MPU-4 содержит:

- коммуникационный ARM контроллер;
- Ethernet;
- коммутатор последовательных интерфейсов RS-232/RS-485.

MPU-5 содержит [[Модуль управления серии СМ_15#^2|следующие разъемы]]:

- для подключения панели управления MMI (Х8);
- для подключения измерительных цепей (Х9);
- для подключения внешних устройств связи: радиомодемов, телефонных модемов, GSM-модемов, устройств прямого соединения (Х10);
- для подключения Ethernet 10BASE-T/100BASE-TX ([[Модуль управления серии СМ_15#^3|Рис. 3]]).

#### Печатный узел DRVU

^drvu

Данный конструктивный узел содержит:

- импульсный преобразователь напряжения для обеспечения электропитанием всех узлов модуля управления;
- мостовой коммутатор;
- конденсаторы включения и отключения для управления электромагнитным приводом вакуумного выключателя;
- релейные выходы сигнализации (2 шт.) и входы управления типа “сухой контакт” (2 шт.).

На печатном узле расположены [[Модуль управления серии СМ_15#^2|три клеммных соединителя WAGO]]:
X5 – для подключения обмотки электромагнитного привода вакуумного выключателя;
X6 – для подключения средств телемеханики к дискретным входам/выходам;
X7 – для подключения к сети оперативного питания.

Узел имеет [[Модуль управления серии СМ_15#^2|три светодиодных индикатора]] для индикации режимов работы модуля:

| Обозначение | Назначение светодиода                |
| ----------- | ------------------------------------ |
| READY       | «ГОТОВ К РАБОТЕ» – светится зелёным  |
| MALFUN      | «НЕИСПРАВНОСТЬ» – светится красным   |
| POWER       | «ПИТАНИЕ В НОРМЕ» – светится зелёным |

#### Печатный узел SBU

^sbu

Данный конструктивный узел выполняет функцию основного питания всех печатных узлов модуля, функцию источника бесперебойного питания всего модуля управления, а также функцию питания внешнего устройства связи (модема).

В состав платы входит:

- интеллектуальное зарядное устройство аккумуляторной батареи;
- сетевой источник питания.

На SBU расположены [[Модуль управления серии СМ_15#^2|два клеммных соединителя WAGO]]:
X3 – для подключения к аккумуляторной батарее, внешнему устройству связи, датчика положения двери;
X4 – для подключения к сети оперативного питания.

Узел имеет [[Модуль управления серии СМ_15#^2|три светодиодных индикатора]] для индикации режимов работы модуля:

| Обозначение | Назначение светодиода                                           |
| ----------- | --------------------------------------------------------------- |
| RTUON       | «ПИТАНИЕ ВНЕШНЕГО УСТРОЙСТВА СВЯЗИ ВКЛЮЧЕНО» – светится зелёным |
| DCHRG       | «АККУМУЛЯТОРНАЯ БАТАРЕЯ РАЗРЯЖАЕТСЯ» – мигает красным           |
| CHRG        | «АККУМУЛЯТОРНАЯ БАТАРЕЯ ЗАРЯЖАЕТСЯ» – светится зелёным          |

#### Печатный узел IOM-2

^iom

Данный конструктивный узел обеспечивает возможность управления и индикации с помощью дискретных входов/выходов. В состав платы входит:

- 6 входов по типу «сухой контакт», имеющих общий вход управления;
- 6 выходов в виде контактов реле.

На IOM-2 расположены [[Модуль управления серии СМ_15#^2|два клеммных соединителя WAGO]]:
X1 – дискретные выходы;
X2 – дискретные входы.

# Монтаж модуля управления

Модуль управления устанавливается в релейном отсеке **в любом пространственном положении**. Крепление осуществляется посредством двух ножек, каждая из которых оснащена двумя монтажными отверстиями (см. [[Модуль управления серии СМ_15#^25|Рис. 25]]).

Все модули серии СМ\_15 унифицированы по габаритным размерам в части ширины и глубины (см. [[Модуль управления серии СМ_15#^34|Рис. 34]]); различия между моделями заключаются исключительно в высоте. Вследствие этого установочные размеры являются едиными для всей серии модулей.
