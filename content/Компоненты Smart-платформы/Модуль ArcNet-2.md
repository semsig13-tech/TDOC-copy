# Назначение

Модуль **ArcNet-2** предназначен для межфидерного и межсекционного обмена данными, а также для работы с датчиками оптической дуговой защиты (ОДЗ) в составе системы дуговой защиты распределительного устройства (РУ).

Модуль обеспечивает:

- межфидерный обмен данными в пределах одной секции РУ по шине CAN FD;
- межсекционный обмен данными по интерфейсу RS-485;
- подключение датчиков ОДЗ.

# Передача данных между ячейками через ArcNet

Канал ArcNet используется для обмена сигналами при реализации распределённых функций РЗА:

1. Дуговая защита (ЗДЗ): фиксация вспышки дуги датчиками ОДЗ и передача сигнала на отключение выключателя.
2. Логическая защита шин (ЛЗШ): передача блокирующего сигнала в сторону вводных (секционных) выключателей в случае, если защиты отходящих линий зафиксировали повреждение.
3. Устройство резервирования отказа выключателя (УРОВ): передача сигнала на отключение вышестоящего выключателя при отказе в отключении собственного выключателя присоединения.
4. Автоматический ввод резерва (АВР) и Восстановление нормального режима (ВНР): обмен сигналами готовности резерва, контроля напряжения и командами на включение/отключение секционных (вводных) выключателей.

# Протокольные особенности и механизмы обмена данными

Для межфидерного обмена в сети ArcNet используется шина CAN FD. На прикладном уровне применяется специализированный протокол ArcNet, предназначенный для передачи сигналов релейной защиты и автоматики.

CAN FD предусматривает приоритетный доступ к шине, контроль ошибок и подтверждение корректного приёма кадров. Механизмы прикладного обмена определяются протоколом ArcNet.

Ниже описаны организация обмена, приоритизация сообщений, контроль ошибок, повторная передача и диагностика сети.

## Приоритизация сообщений и арбитраж шины

Для систем РЗА важное значение имеет своевременная доставка сообщений. При обмене по шине CAN FD используется аппаратный механизм побитового арбитража, определяющий порядок доступа узлов к шине при одновременном начале передачи нескольких кадров.

Приоритет кадра определяется его идентификатором. Для кадров с одинаковым форматом идентификатора меньшее числовое значение идентификатора соответствует более высокому приоритету.

Если несколько узлов одновременно начинают передачу, узел с наиболее приоритетным кадром продолжает передачу. Остальные узлы прекращают передачу, не повреждая передаваемый кадр, и повторно участвуют в арбитраже после освобождения шины.

Сигналам РЗА присвоен повышенный приоритет.

## Непрерывная диагностика

Аппаратный уровень CAN-контроллера и программные механизмы встроенного ПО модуля управления осуществляют непрерывный мониторинг целостности канала. Любое нарушение (обрыв, потеря ответа от узла) фиксируется в журнале неисправностей с выдачей сигнала в SCADA и/или на дискретный выход терминала.

## Механизмы гарантированной доставки

### Бит подтверждения (ACK)

В структуре каждого кадра есть специальный бит. После передачи CRC приемник, получающий сообщение, выставляет подтверждающий бит, если сумма сходится. По этому сигналу передатчик понимает, что сообщение доставлено и не нужно выполнять повторную передачу.

### Повторная отправка сообщений

Некоторые важные сообщения отправляются несколько раз для обеспечения гарантированной доставки (для дуговой защиты обязательно).

### Кадр ошибки (Error Frame)

Кадр ошибки — служебная последовательность протокола CAN FD, включающая флаг ошибки и разделитель ошибки. При обнаружении ошибки CAN-контроллер формирует флаг ошибки в соответствии со своим текущим состоянием.

Узел в состоянии error-active передаёт активный флаг ошибки, который нарушает нормальную передачу текущего кадра. Другие узлы обнаруживают это нарушение и отклоняют кадр. Узел в состоянии error-passive передаёт пассивный флаг ошибки, который не нарушает передачу других узлов.

После неуспешной передачи передатчик повторяет попытку при разрешённой автоматической повторной передаче и получении доступа к шине.

### Контрольная сумма (CRC)

Каждый отправленный кадр содержит контрольную сумму. Принимающий узел вычисляет CRC и проверяет его соответствие значению, переданному в кадре. Несоответствие рассматривается как ошибка приёма. В случае обнаружении ошибки кадр отбрасывается и запрашивается повторно.

## Преимущества технологии

- **Быстродействие передачи:** использование протокольного стека на базе CAN FD обеспечивает время реакции системы, необходимое для ускоренного отключения КЗ (время передачи между устройствами не превышает 5 мс).

- **Снижение объема медного кабеля**: Сокращение количества межъячеечных проводных соединений для сигналов, передаваемых по сети.

- **Помехозащищенность**: дифференциальная передача по витой паре повышает устойчивость шины CAN FD к синфазным помехам, воздействующим на оба проводника линии.

- **Непрерывная диагностика и встроенные аппаратные механизмы гарантированной доставки.**

- **Простая настройка и масштабируемость**: обмен данными между устройствами организован по заранее определённому составу сигналов. Пользователю не требуется вручную задавать перечень передаваемых сигналов, назначать им коммуникационные адреса и настраивать связи между источниками и получателями. Передача осуществляется напрямую между модулями управления, без применения промежуточных сетевых коммутаторов.

# Особенности монтажа

## Межфидерный и межсекционный обмен

Для правильного определения положения в межфидерной и межсекционной сети соединение модулей необходимо выполнять определенным образом. Соединение секций между собой выполняется:

1. Для КРУ Etalon 6(10) кВ - между шкафами [[Модуль ArcNet-2#^3|СВ и СВ]].
2. Для Smart-выключателей 0,4-35 кВ - между ячейками [[Модуль ArcNet-2#^3|СВ и СР]], [[Модуль ArcNet-2#^3|СВ и ОЛ]], [[Модуль ArcNet-2#^5|СВ и ОВ]].

> **Внимание!**
> Применение схемы соединения секций [[Модуль ArcNet-2#^5|СВ и ОВ]] допускается только при наличии ровно одного ввода на каждой секции.

### Организация межфидерной и межсекционной связей для схем "Две секции шин СВ-СВ, СВ-СР"

Соединения модулей необходимо выполнять согласно cхеме [[Модуль ArcNet-2#^3|Рис. 3]], где приведен пример межфидерной связи для классической секции: основной ввод – слева, резервный ввод – справа (секция №1, верхняя часть рисунка), а для организации межсекционной связи приведен пример, где секция №2 – зеркальная, относительно первой секции.

Если схема распределительного устройства представлена одной секционированной выключателями системой шин, то межсекционная связь должна осуществляться между:

- секционными выключателями;
- секционным выключателем и секционным разъединителем: требуется дополнительно установить в ячейке СР модуль управления СМ\_15 с ArcNet;
- секционным выключателем и ближайшей ячейкой ОЛ второй секции: требуется назначить ячейку ОЛ на роль передатчика сигналов между секциями.

### Особенности подключения терминирующих резисторов

Для обеспечения работоспособности CAN шины (для гашения отражений сигнала) на концах линии должны быть подключены терминирующие резисторы.

Модуль ArcNet-2 содержит тумблер для ручного подключения /отключения терминирующего резистора.  Резисторы должны быть включены на двух физических концах каждого сегмента CAN FD (один сегмент CAN FD соответствует одной секции). На промежуточных узлах согласующие резисторы должны быть отключены.

Модуль ArcNet включается в коммуникационную цепь между панелью управления (MMI) и модулем управления (CM\_15). Питание модуля ArcNet осуществляется от модуля управления по соединительному шлейфу, дополнительное питание не требуется.

Перед использованием требуется убедиться в совместимости версий ПО модуля ArcNet\_2 модуля управления CM\_15.
Обновление программного обеспечения производится совместно с модулем управления. Подробнее см. в [[КРУ|обновление ВПО для КРУ]].
